## 0. 산업 범위 정의

| 항목 | 내용 |
|---|---|
| **정의** | 신선식품을 **직매입**하여 자체 **콜드체인 물류**로 보관·분류하고, 전날 주문분을 **익일 새벽에 배송**하는 리테일테크 기반 이커머스 |
| **수익 모델** | 상품 판매 마진(매입가 ↔ 판매가) + 멤버십 구독료 — **거래액 자체가 매출** |
| **자산 구조** | **Asset-heavy** — 물류센터·냉장설비·배송망 보유, 고정비 매우 높음 |
| **핵심 역량** | 수요 예측(폐기율 관리) · 배송 밀도(density) · 콜드체인 운영 |
| **분석에서 제외** | 판매자를 중개만 하는 오픈마켓형 식품 판매 (재고를 지지 않아 구조가 다름) |

> ⚠️ **범위 설정의 핵심 판단** — 이 산업의 정체성은 '이커머스'가 아니라 **'물류업'** 에 가깝습니다.
> 재고를 직접 떠안고, 시간이 지나면 상품이 **썩는다**는 점이 다른 모든 유통업과 구분되는 지점입니다.

## 1. 공급자 교섭력 — 🟡 **Medium**

**공급자 = 산지 생산자 + 식품 제조사 + 물류 인프라/인력**

| 공급자 유형 | 교섭력 | 설명 |
|---|:--:|---|
| 산지 농·수·축산 생산자 | 🟢 낮음 | 극도로 파편화 → 개별 협상력 미약 |
| **대형 식품 제조사** | 🔴 **높음** | 특정 인기 브랜드 상품은 없으면 고객이 이탈 → 강한 협상력 |
| **원물 시장 자체** | 🔴 **높음** | 기후·작황에 따라 매입가가 급등락 — *협상 상대가 아니라 자연* |
| 콜드체인 설비 | 🟡 중간 | 대체 가능하나 초기 투자 규모가 큼 |
| **새벽 배송 인력** | 🔴 **높음** | 심야 노동 특성상 인력 확보난 → 인건비 상승 압력 상시 |

| 판단 요소 | 관찰 | 방향 |
|---|---|:--:|
| 원가 비중 | 매출원가가 손익의 대부분 → 공급가 1%가 마진을 좌우 | ↑ 강화 |
| 완화 수단 | **PB(자체 브랜드) 개발**, 산지 직계약으로 의존도 축소 가능 | ↓ 약화 |
| 전방 통합 위협 | 생산자가 직접 온라인 판매(산지직송)에 나설 수 있으나 새벽배송 물류를 갖출 수 없음 | ↓ 약화 |

**판단** · 개별 생산자는 약하지만, **날씨와 인건비라는 '협상 불가능한 공급자'** 가 실질적인 압력의 원천입니다. 전략으로 통제하기 어려운 종류의 힘이라는 점이 이 산업의 까다로움입니다.

## 2. 구매자 교섭력 — 🔴 **High** (단, 완화 가능성 있음)

| 판단 요소 | 관찰 | 방향 |
|---|---|:--:|
| 전환 비용 | 앱 여러 개를 동시에 깔아두고 그날 싼 곳에서 구매 — 사실상 0 | ↑ 강화 |
| 가격 민감도 | 식품은 **가격 탄력성이 큰** 품목. 쿠폰·할인에 즉각 반응 | ↑ 강화 |
| 상품 표준화 | 동일 제조사 브랜드 상품은 어디서 사도 같음 → 가격만 남음 | ↑ 강화 |
| **구매 빈도** | 식품은 **주 1~2회 반복 구매** → 습관이 형성되면 강력한 락인 | ↓ **약화** |
| 멤버십 락인 | 구독료 선지불 + 무료배송 혜택 → 본전 심리로 이탈 억제 | ↓ 약화 |
| 신선도 신뢰 | "이 앱 채소는 실패가 없다"는 경험이 쌓이면 가격을 넘어서는 저항 발생 | ↓ 약화 |

**판단** · 현재는 High이지만, **숙박 공유와 결정적으로 다른 점은 고빈도 구매**라는 사실입니다. 반복 구매는 습관을 만들고, 습관은 전환 비용을 *인위적으로 창출*합니다. 이 산업에서 멤버십과 신선도 신뢰에 사활을 거는 이유가 여기 있습니다.

## 3. 신규 진입자 위협 — 🟢 **Low**

| 진입 장벽 | 높이 | 설명 |
|---|:--:|---|
| **초기 자본(CAPEX)** | 🟢 매우 높음 | 콜드체인 물류센터 구축에 대규모 투자 필요 |
| **규모의 경제 = 배송 밀도** | 🟢 매우 높음 | 같은 동네에 주문이 촘촘해야 단위 배송비가 떨어짐. **밀도 없이는 무조건 적자** |
| 수요 예측 역량 | 🟢 높음 | 폐기율을 못 잡으면 팔수록 손해 — 데이터 축적에 시간 필요 |
| 지역 확장의 비선형성 | 🟢 높음 | 신규 권역마다 물류센터를 새로 지어야 함 → 확장 비용이 계단식 |
| **인접 산업의 진입** | 🔴 **위협** | 기존 대형 유통사·빅테크는 자본과 고객을 이미 보유 → 마음먹으면 진입 가능 |

**판단** · 맨땅에서 시작하는 신규 진입자는 사실상 불가능합니다. 다만 위협의 형태가 다릅니다 — **스타트업이 아니라 이미 자본과 트래픽을 가진 거인의 카테고리 확장**이 실질적 위협입니다.

> 💡 **학습 포인트** — 진입 장벽을 볼 때는 "누가 못 들어오는가"만이 아니라 **"누구는 들어올 수 있는가"** 를 함께 물어야 합니다.

## 4. 대체재 위협 — 🟡 **Medium**

**"오늘 저녁 먹을 것을 마련한다"는 욕구를 채우는 다른 수단**

| 대체재 | 위협 수준 | 설명 |
|---|:--:|---|
| **즉시배송·퀵커머스** | 🔴 | 30분 배송이 '새벽까지 기다림' 자체를 무의미하게 만듦 — **시간축에서의 대체** |
| 오프라인 마트·전통시장 | 🟡 | 직접 보고 고르는 경험. 신선식품에서는 여전히 강력 |
| 편의점·동네 슈퍼 | 🟡 | 소량·즉시 구매 수요 흡수 |
| **밀키트·가정간편식** | 🟡 | 식재료 구매와 조리 과정 **자체를 우회** |
| 음식 배달·외식 | 🟡 | '요리한다'는 행위를 통째로 대체 |

**판단** · Medium으로 판단한 근거는 **신선식품이 완전히 대체되기 어려운 품목**이기 때문입니다. 사람은 계속 장을 봅니다. 다만 *언제·어디서 사는가* 를 두고 대체재가 계속 침식합니다. 특히 **퀵커머스의 성장은 새벽배송의 존재 이유(시간 우위)를 직접 겨냥**합니다.

## 5. 기존 경쟁 강도 — 🔴 **High** (매우 강함)

| 판단 요소 | 관찰 | 방향 |
|---|---|:--:|
| 경쟁사 수 | 대형 이커머스 + 전문 새벽배송 + 기존 유통 대기업의 온라인 부문 | ↑ 강화 |
| **고정비 구조** | 물류센터는 **가동률을 채워야 단가가 맞음** → 적자라도 물량을 밀어넣게 됨 | ↑ **강화** |
| **철수 장벽** | 물류센터·냉장설비는 **매몰 비용**. 접고 나갈 수 없어 적자여도 버팀 | ↑ **강화** |
| 시장 성장률 | 초기 고성장이 꺾이는 국면에서는 **파이 뺏기 싸움**으로 전환 | ↑ 강화 |
| 차별화 정도 | 브랜드 상품은 동일 → 가격·배송시간·큐레이션 외에 차별점 만들기 어려움 | ↑ 강화 |

**판단** · 이 산업에서 경쟁 강도가 극심한 이유는 경쟁사가 많아서가 아니라 **구조 때문**입니다.

```
높은 고정비 → 가동률을 채워야 함 → 손해 보면서도 물량 확보
     +
높은 철수 장벽 → 적자여도 나갈 수 없음 → 좀비 경쟁자가 시장에 잔류
     ↓
      가격이 회복되지 않는 만성 출혈 경쟁
```

**진입 장벽을 만들어준 바로 그 자산(물류센터)이, 동시에 철수를 막는 족쇄가 됩니다.**

## 6. 종합 판단 — 산업 매력도

| 힘 | 강도 | 한 줄 요약 |
|---|:--:|---|
| 공급자 교섭력 | 🟡 Medium | 생산자는 약하나 날씨·인건비는 협상 불가 |
| 구매자 교섭력 | 🔴 High | 가격 민감. 단 고빈도라 습관 락인 가능 |
| 신규 진입자 위협 | 🟢 **Low** | CAPEX와 배송 밀도가 강력한 방벽 |
| 대체재 위협 | 🟡 Medium | 퀵커머스가 시간 우위를 직접 위협 |
| 기존 경쟁 강도 | 🔴 **High** | 고정비 + 철수장벽 조합이 만성 출혈을 강제 |

### 결론

**구조적 매력도: 중(中). 단, 승자만 살아남는 구조.**

진입 장벽이 다섯 힘 중 가장 유리한 항목인데도 산업 전체 수익성은 좋지 않습니다. 이유는 명확합니다 — **진입 장벽을 세운 대가로 철수 장벽까지 함께 떠안았기 때문**입니다.

- 신규 경쟁자는 못 들어오지만, **이미 들어온 경쟁자는 나가지도 않습니다**
- 규모를 확보하기 전까지는 확장할수록 적자가 커지는 구간을 지나야 합니다
- 그 구간을 통과해 **밀도를 확보한 소수**에게는 반대로 강력한 해자가 남습니다

즉 **'버티면 이기지만, 버티는 비용이 극단적으로 비싼'** 산업입니다.

## 7. 전략 도출

| 전략 방향 | 적합도 | 근거 |
|---|:--:|---|
| **저비용(원가 우위)** | ⭐⭐⭐ | 배송 밀도 → 단위 원가 하락 → 가격 경쟁력 → 주문 증가 → 밀도 강화. 이 선순환이 유일한 정공법 |
| **집중화** | ⭐⭐⭐ | 전국이 아닌 **특정 권역·특정 카테고리(예: 친환경 전문)** 에서 먼저 흑자 구조를 완성 |
| 차별화 | ⭐⭐ | PB·큐레이션·신선도 보증으로 가능하나, 브랜드 상품 영역에서는 한계 |

**실행 관점 우선순위**
1. **밀도 우선, 커버리지 나중** — 넓게 펴는 순간 단위 경제가 무너진다. 권역별 흑자 전환을 확인하고 확장
2. **폐기율 관리가 곧 마진** — 수요 예측 정확도가 이 산업의 진짜 기술 경쟁력
3. **멤버십으로 빈도 락인** — 고빈도라는 유일한 우위를 전환 비용으로 전환
4. **PB 비중 확대** — 공급자 교섭력을 낮추는 동시에 가격 비교 자체를 무력화

## ⚠️ 6번째 힘 — 규제

- **심야·새벽 노동 관련 규제** — 배송 인력의 근로 조건 규제가 강화되면 원가 구조가 직접 타격
- **유통 규제** — 대형마트 의무휴업 등 오프라인 규제가 온라인 배송으로 확대 논의될 경우 영향
- **식품 안전·콜드체인 위생 기준** — 강화 시 고정비 상승이지만, 동시에 **진입 장벽을 더 높이는 효과**

> 📌 규제는 이 산업에서 **원가와 진입 장벽에 동시에 작용**합니다. 신규 진입자에게 불리하고 기존 대형 사업자에게 유리한 방향으로 작동하는 경향이 있습니다.
